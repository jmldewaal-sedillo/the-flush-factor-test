# the-flush-factor-test

Dit is de **testversie** van `the-flush-factor` (branch `main`), gepubliceerd op
https://jmldewaal-sedillo.github.io/the-flush-factor-test/ (noindex; nergens naar linken). Niet de app zelf.

Deze branch `standaard` is de standaardbranch en bestaat alleen zodat Dependabot hier niets doet:
Dependabot leest `.github/dependabot.yml` op de standaardbranch, en op `main` komt dat bestand met
elke push vanuit de hoofdrepo mee. Updates en meldingen horen in de hoofdrepo
https://github.com/jmldewaal-sedillo/the-flush-factor, niet hier.

Nieuwe versie op het testadres (vanuit de hoofdrepo): `git push test <branch>:main`.
Zie `docs/testversie.md` in de hoofdrepo en `Apps/tools/test-repo-dependabot-uit.sh`.
